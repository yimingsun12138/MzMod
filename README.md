# MzMod

用于《暗黑破坏神II：重制版》的物品显示与界面增强Mod。

作者：Yiming Sun, helped by Codex  
当前版本：0.1.0  
更新时间：2026/11/14（UTC）

## 项目动机

MzMod让物品辨识、魔盒操作和场景指引更清晰便捷，保留官方玩法与装备数值。

## 下载与安装

| 区域 | 完整Mod目录 | 基于游戏版本 |
| :---: | :---: | :---: |
| 国际服 | [MzMod_INT/MzMod](MzMod_INT/MzMod/) | 3.4.95032 |
| 国服 | [MzMod_CN/MzMod](MzMod_CN/MzMod/) | 3.4.95039 |

两区各自提供完整Mod，按所在区域选择对应目录，复制即可安装。

1. 下载仓库ZIP并解压，或克隆仓库，找到对应区域目录中的`MzMod`文件夹。
2. 关闭游戏；更新时先移走旧的`mods/MzMod`文件夹，再把新的`MzMod`复制到游戏的`mods`目录。
3. 确认目录结构如下，设置启动参数`-mod MzMod`。

```text
Diablo II Resurrected/
└── mods/
    └── MzMod/
        └── MzMod.mpq/
            ├── modinfo.json
            └── data/
```

安装时取出区域目录内部的`MzMod`即可，不要把外层的`MzMod_INT`或`MzMod_CN`放入`mods`。取消使用时移除启动参数`-mod MzMod`。

## 功能

本版用于HD画面。语言、物品过滤规则和地面标签显示方式通过游戏原生设置选择。

| 功能 | 使用规则 |
| :---: | :---: |
| 语言与字体 | 中文使用繁体译名和自定义字体；英文使用英文名称与提示。 |
| 装备名称 | 中文界面中的暗金、套装、符文之语和符文名称提供英文对照。 |
| MAX提示 | 中英文名称显示部分装备可变属性的最高值，帮助辨识属性范围。 |
| 底材标记 | 底材名称显示普通、扩展或精英阶级；适用的护甲与盾牌显示轻、中、重分类。 |
| 符文 | 名称与物品栏图标显示编号；#10–#32增加中英文升级材料行。 |
| 名称颜色 | 无形且无孔为淡青色；有孔为淡粉紫色。 |
| 掉落光柱 | #25 Gul至#33 Zod、滅絕和地獄火炬显示光柱。 |
| 场景指引 | 地图入口、小站、沃特之厅方向及赫拉森的日誌提供位置标记；女伯爵任务书与藍伊森之書增加定位光效。 |
| 迷你魔盒 | 入局自动打开；键鼠入口位于装备栏右下角，手柄使用独立入口。面板贴齐画面右下角，转化与关闭按钮在左侧竖排。 |
| 界面 | 调整HUD、怪物与佣兵血条、中文退出文字和设置滑块数值的显示。 |

完整功能、覆盖范围和符文升级配方见[更新记录](CHANGELOG.md)。

## 使用反馈

Mod中的部分数值提示由Codex搜集并整合互联网资料形成，可能存在错误或未及时跟随游戏版本更新。欢迎通过本仓库的Issue反馈数值错误、版本差异或其他使用问题。

反馈问题时，请注明区域、客户端版本、语言、输入方式和复现步骤；涉及界面布局时，请同时注明分辨率与画面比例。

反馈数值问题时，请说明具体物品或属性；附上游戏内实际数值、截图或资料链接，有助于核对。
