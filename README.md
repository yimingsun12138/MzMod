# MzMod

用于《暗黑破坏神II：重制版》的物品显示与界面增强Mod。

作者：Yiming Sun, helped by Codex  
当前版本：v0.1.1  
更新时间：2026/11/24（UTC）  
适配游戏版本：《术士君临》国际服v3.4.95032、国服v3.4.95039

## 项目动机

MzMod在物品名称中标注底材阶级和部分可变属性的上限，便于玩家辨识与比较装备。场景中的光效帮助定位入口、小站和任务目标，迷你魔盒提供直接操作盒内物品的界面。游戏沿用官方玩法与装备数值。

## 下载与安装

请从本项目的GitHub发布页下载[适用于Windows x64的MzMod设置器（MzModController_v0.1.1.exe）](https://github.com/yimingsun12138/MzMod/releases/download/v0.1.1/MzModController_v0.1.1.exe)。设置器内置国际服和国服的模组文件，运行后可选择所用区服。

### 使用Windows设置器

1. 退出游戏客户端，启动MzMod设置器。
2. 在设置器右上角选择与游戏客户端对应的区服（国服或国际服）。
3. 在左侧各功能页设置掉落光柱、物品名称显示、场景指引等选项。
4. 在窗口底部选择输出位置。「选择游戏目录」用于直接安装或更新模组，需指定`D2R.exe`所在的目录。「默认位置」用于在设置器所在目录下生成模组。两种方式的实际路径均显示在「输出到」一栏。
5. 点击「应用全部更改」生成模组。若输出路径为游戏目录下的`mods/MzMod`，生成后即完成安装。若输出到其他位置，将生成的`MzMod`文件夹完整复制到相应区服游戏目录的`mods`文件夹下。手动更新时，先移出该目录中的旧版`MzMod`文件夹，再复制新版。
6. 在战网客户端添加游戏启动参数`-mod MzMod`，随后启动游戏。停用模组时，移除该参数并重启游戏。

## 功能

下表列出v0.1.1在HD画面下的默认显示与操作方式。玩家可在设置器中调整模组功能，在游戏内选择语言、物品过滤规则和地面标签的显示方式。

| 功能 | 使用规则 |
| :---: | :---: |
| 语言与字体 | 中文使用繁体译名和自定义字体，英文使用英文名称与提示。 |
| 装备名称 | 中文界面中的暗金、套装、符文之语和符文名称提供英文对照。 |
| MAX提示 | 部分装备的中英文名称标注可变属性的上限，可与该件装备的实际属性比较。 |
| 底材标记 | 底材名称标注普通、扩展或精英阶级。适用的护甲与盾牌另标注轻、中、重分类。 |
| 符文 | 符文名称与物品栏图标均显示编号。#10–#32升级时还需消耗宝石，其完整名称另列升级材料，支持中文与英文。 |
| 名称颜色 | 无形且无孔的物品名称显示为淡青色。有孔物品（包括无形且有孔的物品）名称显示为淡粉紫色。 |
| 掉落光柱 | #25 Gul至#33 Zod、滅絕和地獄火炬显示光柱。 |
| 场景指引 | 小站和地图入口带有光效指引，七座古墓的入口点亮各自的符号。沃特之厅标出前往尼拉塞克的方向，赫拉森的日誌带有位置标记。女伯爵古书与藍伊森之書的书页周围显示淡金色光晕。 |
| 技能护眼 | 法师雷云风暴与刺客元素武学默认开启护眼效果，可分别关闭。 |
| 迷你魔盒 | 进入游戏后自动打开。键鼠入口位于装备栏右下角，手柄使用独立入口。面板贴齐画面右下角，转化与关闭按钮在面板左侧竖排。 |
| 界面 | 调整HUD、怪物血条、佣兵名称排版（仅国服）、中文退出文字和设置滑块数值的显示。 |

完整功能和覆盖范围见[更新记录](CHANGELOG.md)。

### 从源码构建Windows设置器

下载与所需模组版本标签对应的完整源码。在Windows x64上安装Rust的MSVC工具链及Visual Studio Build Tools中的C++桌面开发组件（含Windows SDK）。在源码根目录打开PowerShell，运行以下命令。

```powershell
cd Controller
cargo build --locked --release --target x86_64-pc-windows-msvc
```

生成的程序位于`Controller/target/x86_64-pc-windows-msvc/release/MzModController.exe`。GitHub发布页上的附件名包含版本号，例如`MzModController_v0.1.1.exe`。

编译时，两区资源与各项功能的默认值一并嵌入设置器。两区共用资源位于`ModTemplate/common/`，国际服和国服的专用资源分别位于`ModTemplate/INT/`和`ModTemplate/CN/`。如需更改首次使用或恢复默认时的设置，请在[默认配置文件](ModTemplate/defaults.json)中将相应项设为`true`（开启）或`false`（关闭），然后重新编译。其中，`rune_beams`数组的33项依次对应#1至#33符文的掉落光柱。

点击「应用全部更改」后，设置器读取所选区服的资源，按勾选项生成`MzMod/MzMod.mpq/`，并将本次选择保存在`MzMod/controller-settings.json`。物品开关使用的名称与模型数据见[items.json](ModTemplate/items.json)。场景、技能、迷你魔盒与界面外观开关使用的资源映射见[visuals.json](ModTemplate/visuals.json)。

## 使用反馈

模组中的部分数值提示依据Codex搜集和整理的公开资料编写。资料可能有误，提示也可能未反映后续游戏版本的变化。欢迎在本仓库的Issues中反馈数值差异或其他使用问题。

反馈时，请注明区服、客户端版本、语言、输入方式和复现步骤。涉及界面布局时，请同时注明分辨率与画面比例。

反馈数值差异时，请列出物品名称、具体属性与模组提示值。若有对应的游戏内数值、截图或资料链接，请一并提供，以便核对。
